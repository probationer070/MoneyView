## 0. 요청과 범위

소유자 요청(2026-11-02): 기업 분석 탭의 설명이 부족합니다. 예를 들면 다음과 같습니다.

- 진단 차트에서 베타가 1보다 크면 무슨 뜻인지
- 허들레이트를 무엇과 비교해야 하는지
- 4분면 가치 매트릭스가 무엇을 뜻하고 어떻게 읽는지
- 종목 비교의 각 값이 무엇을 뜻하는지

이런 부분을 자료 조사, 검색, 계산으로 검증하고, 보완할 점을 계획으로 정리합니다.

**범위:** 기업 분석(`/corporate`)의 네 탭(요약, 진단 차트, DCF, 종목 비교)과 헤더입니다.

**핵심 원칙: 설명은 코드가 실제로 하는 일만 말합니다.**
검증해 보니 진단 차트의 일부 값은 계산이 아니라 고정값이거나 임의로 만든 식이었습니다(§3).
이런 값에 "업계 베타", "시장 내재 ERP" 같은 이론적 설명을 붙이면 거짓 설명이 됩니다.
그래서 이 계획은 두 갈래로 나뉩니다.

1. 그대로 둔 채 사실대로 설명할 것
2. 먼저 고치거나 "예시값"으로 표시한 뒤에 설명할 것

## 2. 현재 화면 인벤토리와 부족한 설명

| 탭 / 요소 | 지금 보이는 설명 | 부족한 점 |
|---|---|---|
| 헤더: DCF 판정, 다모다란식 적정가 | 판정 문구, 적정가와 괴리율, 내재 성장률 | 5년 DCF와 다모다란 10년 적정가가 **서로 다른 모델**이라는 설명이 없음 |
| 요약: KPI 4개(ROIC−WACC, 상향식 Ke, WACC, 레버리지 베타) | 카드 아래 한 줄 | Ke와 WACC의 차이, 그리고 각각 무엇과 비교해야 하는지 없음 |
| 요약: 가정 표 | 행마다 ⓘ, 상태 배지(Estimated/OK) | 배지의 뜻, "국가위험프리미엄 0.8% 고정"의 이유 없음 |

| 진단: 상향식 베타 + WACC U-커브 | 영어 툴팁 1문장 | 베타 1 기준의 뜻, 세 막대의 차이, U-커브 읽는 법, 점선의 뜻 없음 |
| 진단: 4분면 가치동인 매트릭스 | 영어 툴팁 1문장 | 4분면 각각의 뜻이 없음. X축 기준선이 없어 4분면이 그려지지도 않음. 비교점(Peer A/B/C)의 정체 없음 |
| DCF 탭 | 탭 ⓘ 1문장 | 민감도표 읽는 법, 영구가치 비중의 뜻 |
| 종목 비교: 표 11열 | 열 이름(영어)과 거절 사유 title | 열별 정의, 단위, 좋고 나쁨의 방향 없음. "Market Return"이 모든 행에서 같은 이유 없음 |
| 종목 비교: 막대·산점도 | 없음 | 대각선(가치 = 가격) 의미, 버블 크기의 뜻 없음 |

차트 제목, 툴팁, 표 머리글은 하드코딩된 영어라 한국어 모드에서도 영어로 나옵니다(`graphs/*.tsx`, `CorporateComparisonTable.tsx:49-60`).

## 3. 검증 결과 (설명하기 전에 바로잡아야 할 것)

심각도는 다음 기준입니다.
- **A:** 화면이 사실과 다른 것을 주장함
- **B:** 계산이 서로 일관되지 않음
- **C:** 설명만 부족함

### V1 (A): "시장 내재 ERP"가 실제로는 상수 4.06%
- 코드(`corporateUtils.ts:280-313`)는 첫해 현금흐름을 `지수 × (배당 1.4% + 자사주 2.3%)`로 정한 뒤, PV가 지수와 같아지는 할인율을 구합니다.
- 현금흐름이 지수에 비례하므로 **지수 수준이 약분되어 답에 영향을 주지 않습니다.** 성장 경로(7→4.2%)와 수익률도 상수입니다.
- 재현 결과, 지수 100과 6800 모두 시장 IRR 8.264%, ERP **4.064%**로 같았습니다. S&P 500 시세를 불러오지만 결과는 바뀌지 않습니다.
- 비교: 다모다란의 2026년 내재 ERP는 4.23%(1월), 4.24%(5월)로 보도되었습니다. 우연히 비슷하지만 "시장에서 실시간으로 내재 추출"했다는 화면 설명은 사실이 아닙니다.

### V2 (B): 같은 화면에 할인율 체계가 두 개
- KPI "상향식 Ke"(프런트): `4.2% + β_L × 4.06% + 0.8%`. β_L은 세율 25%로 하마다 재레버합니다.
- KPI "WACC"(백엔드, `corporate_statement_metrics.py`): `4.2% + β_L × 5.5% + 0.8%`. β_L은 실제 세율을 쓰고, 가중치는 장부가입니다.
- 실측:

  | 종목 | Ke(프런트, 화면) | Ke(백엔드, WACC 안) | WACC |
  |---|---|---|---|
  | AAPL | 9.15% | 10.96% | 6.62% |
  | NVDA | 14.03% | 17.36% | 15.65% |

- 결과: 화면의 Ke는 WACC를 만든 Ke가 아닙니다. NVDA는 화면만 보면 "Ke 14.0% < WACC 15.65%"처럼 보이는데, 정상이라면 Ke가 WACC보다 커야 합니다(부채가 더 싸므로).

### V3 (A/B): 한국 CRP 0.8%가 미국 종목에도 붙음
- `KOREA_COUNTRY_RISK_PREMIUM = 0.8`이 모든 종목의 Ke에 더해집니다(프런트, 백엔드 모두). 계산식 문서 §16 1번 항목입니다.
- 그런데 같은 차트의 지역 막대는 "US CRP 0.0%"라고 표시합니다. 화면 안에서 서로 모순됩니다.
- 다모다란 방식은 국가위험을 상장국이 아니라 **사업 노출**로 반영합니다.
  - 매출 가중 평균 CRP, 또는 `Ke = r_f + β × 성숙시장 ERP + λ × CRP`(λ = 그 나라 노출도)를 씁니다.
  - 미국 매출 중심 기업의 CRP는 0에 가깝습니다.

### V4 (A): 지역 허들레이트 막대 4개는 고정 예시값
- `page.tsx:803-808`의 값은 모든 종목에서 같습니다.
  - 지역별 가산치: EU +0.2/+0.4, Korea +0.4/+1.2, Emerging +0.9/+2.1
  - 매출 비중: 46/22/12/20
- 회사의 실제 지역 매출과는 관계가 없는데, 상세 창은 "revenue weight"라고 표시합니다.

### V5 (A): 베타 막대 3개 중 둘은 이름과 실제 계산이 다름

| 막대 | 화면 설명 | 실제 계산 |
|---|---|---|
| Industry | 업종의 순수 사업위험 | 회사의 비레버 베타(Yahoo 베타를 디레버). 업종 값이 아님 |
| Operating | 재무구조를 뺀 자산위험 | `clamp(0.75 + 재투자율/100, 0.6, 1.8)`: 근거 없는 식, 대부분 약 0.75 (AAPL 0.75, NVDA 0.78) |
| Financial | 부채로 인한 추가 위험 | 레버리지 베타 전체(β_L). "추가분"(β_L − β_U)이 아님 |

- 또한 상세 창 sourcing 표는 Operating 값을 β_U로 적어, 막대 값과도 다릅니다.
- 다모다란의 "상향식 베타"는 **업종 평균 비레버 베타(사업 비중 가중) → 회사 D/E로 재레버**하는 방식입니다. 지금은 회사 자신의 회귀 베타를 씁니다.

### V6 (A): WACC U-커브는 고정된 그림
- 식: `WACC − 2.4 × d/45 + 3.2 × (d/70)²`(`page.tsx:816-820`)
- 꼭짓점이 모든 종목에서 **부채비율 40.8%**에 고정되고, 곡선 모양도 모든 종목에서 같습니다. 높이만 WACC만큼 움직입니다.
- 또 곡선의 0% 지점 값이 현재 WACC와 같아, 현재 부채비율(점선) 위치의 값과 일치하지 않습니다. AAPL은 57%에서 곡선 값이 약 6.0%인데, 표시되는 WACC는 6.62%입니다.
- 다모다란의 "자본비용 접근법"은 부채비율마다 다음을 다시 계산해 최소점을 찾습니다.
  - 이자보상배율 → 합성 신용등급 → 부채비용
  - 재레버된 Ke
- 그래서 최적점은 회사마다 다릅니다(예: Disney 40%, Baidu 0–10%).

### V7 (A/C): 4분면 매트릭스의 비교점 3개는 가짜 고정점
- `Peer A (4.2%, +3.4%p)`, `Peer B (8.5%, −1.8%p)`, `Peer C (2.1%, +7.2%p)`가 모든 종목에 똑같이 찍힙니다(`page.tsx:833-835`). 상세 창은 "Static peer scenario"라고 적지만 화면에서는 보이지 않습니다.
- 수평선(ROIC = WACC)만 있고 성장 기준 수직선이 없어서 실제로는 4분면이 나뉘지 않습니다.
- 상세 창의 "Quadrant" 판정은 두 가지 문구뿐입니다("Growth + value creation" / "Review required").
- X축은 매출 CAGR이라 NVDA(120%) 같은 값이 축을 늘려 다른 점을 뭉갭니다.

### V8 (C): 재투자율 정의가 좁음
- 재투자율은 `max(capex − 감가상각, 0) / NOPAT`이고, 운전자본 증가와 인수는 빠집니다(`corporate_statement_metrics.py:805-811`).
- 그 결과 AAPL 0.23%, 지속가능 성장률 0.14%로, 실제 매출 성장률 1.81%와 따로 놉니다.
- 설명에 "운전자본과 인수는 포함하지 않음"을 반드시 적어야 합니다.

### V9 (B): 고정 자리표시값
- `market_share 64`, `governance 74`, `esg_penalty 22`가 AAPL과 NVDA에서 같습니다. 백엔드 fallback 상수로 보입니다.
- 화면 어디에 쓰이는지 확인하고, 쓰인다면 "측정값 아님"이라고 표시해야 합니다.

### V10 (C): 종목 비교 열 정의 (계산식 문서 §3 기준, 설명만 부족)

| 열(현재 영어) | 정의 | 읽는 방향 |
|---|---|---|
| Weight | 포트폴리오 비중. 비중 정보가 없으면 동일가중 1/n(`corporate_comparison.py:1056`) | 정보 |
| ROIC − WACC | 투하자본수익률 − 자본비용(%p) | +면 가치 창출, −면 성장할수록 가치 파괴 |
| DCF Value | 5년 FCFF DCF 주당가치. 브리지 실패 시 표시 안 함 | 현재가와 비교 |
| Current Price | 최근 종가 | — |
| DCF value vs price (one-off gap) | 주당가치/현재가 − 1. 연율이 아니라 "한 번에 메워질 괴리" | +면 저평가 신호 |
| CAPM Return | r_f + β_L × 5.5%: 위험 대비 **요구**수익률 | 내 기대수익률이 이보다 높아야 함 |
| Market Return | r_f + ERP = 9.7%. 모든 행이 같은 값(시장 전체 기준) | 기준선 |
| Market-implied return (per year) | 현재 시가총액(EV)을 정당화하는 할인율 r*: 지금 사면 모델상 기대되는 연수익률 | 클수록 쌈 |
| Implied return vs WACC | r* − WACC(%p/년) | +면 가격이 자본비용보다 높은 수익을 암시(저평가) |

산점도의 대각선(가치 = 가격) 위는 저평가, 아래는 고평가입니다. 버블 크기는 |r* − WACC|입니다. 이 설명이 화면에 없습니다.

## 4. 넣을 설명 초안 (소유자가 질문한 항목)

격식체이며, 숫자는 화면 값을 끼워 넣습니다. 고정값이 확정되지 않은 부분은 §5 결정 뒤에 문구를 확정합니다.

**베타가 1보다 크면.**
베타는 이 종목이 시장(S&P 500)보다 얼마나 크게 움직이는지 보여 줍니다.
1이면 시장과 같고, 1.5면 시장이 10% 움직일 때 평균 15% 움직입니다. 0.5면 5%입니다.
1보다 크면 투자자가 더 높은 수익을 요구하므로 자기자본비용(Ke)이 올라가고, DCF 가치는 내려갑니다.
- 비레버 베타: 부채가 없다고 가정한 사업 자체의 위험입니다.
- 레버리지 베타: 부채를 반영한 값입니다.
  `β_L = β_U × [1 + (1 − 세율) × 부채/자기자본]`
  부채가 많을수록 주주 위험이 커집니다.

**허들레이트는 무엇과 비교하나.**
허들레이트는 투자가 넘어야 할 최소 수익률입니다. 비교 대상은 짝이 정해져 있습니다.

| 이 값을 | 이것과 비교 | 뜻 |
|---|---|---|
| ROIC(사업이 버는 수익률) | WACC | ROIC > WACC면 사업이 가치를 만듭니다(요약 카드 ROIC − WACC) |
| 시장 암시 수익률 r*(지금 가격에 산 투자자의 기대수익률) | WACC | r* > WACC면 가격이 싸다는 신호(종목 비교 마지막 열) |
| 내가 기대하는 주식 수익률 | Ke(CAPM 수익률) | Ke는 주주의 최소 요구수익률. 기대가 Ke보다 낮으면 위험 대비 보상이 부족 |

Ke와 WACC를 서로 비교하지 않습니다. WACC는 Ke와 세후 부채비용의 가중평균이라 보통 Ke보다 낮습니다.

**4분면 가치 매트릭스.**
세로축은 ROIC − WACC(가치 창출력), 가로축은 성장률입니다.
- 오른쪽 위(고성장·가치 창출): 성장이 곧 가치. 성장에 투자할수록 좋아집니다.
- 왼쪽 위(저성장·가치 창출): 돈은 잘 벌지만 재투자처가 부족. 배당·자사주가 유력합니다.
- 오른쪽 아래(고성장·가치 파괴): 성장할수록 가치가 줄어듭니다. 수익성 개선이 먼저입니다.
- 왼쪽 아래(저성장·가치 파괴): 구조조정이 필요한 영역입니다.

근거: McKinsey(Koller 등)는 ROIC가 WACC보다 높을 때만 성장이 가치를 더하고, ROIC = WACC면 성장은 가치에 영향이 없으며, 낮으면 빨리 클수록 가치를 더 잃는다고 봅니다.
버블 크기는 FCFF(잉여현금흐름) 규모입니다.

**종목 비교 열:** §3 V10 표를 그대로 열 머리 ⓘ와 탭 가이드에 넣습니다.
