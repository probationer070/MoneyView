# Monte Carlo 한 화면 재구성 설계

Oct 16, 2026 · 근거 코드는 `renewal` b833b21이다. 경로는 따로 적지 않으면 `apps/web/` 아래다. 높이는 이 설계를 위해 1280×720에서 잰 값이다.

## 배경과 목표

모든 페이지 원칙(2026-10-14): 1280×720에서 페이지 스크롤이 없어야 한다. 작업 화면은 핵심 수치를 먼저 보이고 나머지는 탭이나 패널 안 스크롤로 보낸다. 참조 구현은 `/corporate`와 `/`다.

|---|---|---|
| 경로 | 1636 | 1788 |
| 위험 | 726 | 1892 |

| 기업가치 | 1042 | — |

경로 탭 하나에 다음이 세로로 쌓인다.
- 입력 8칸과 실행 버튼
- 실행 모드 안내 상자
- 요약 카드(설명문, 항목 4개, CSV 버튼 4개)

스타일 조정으로는 맞출 수 없다. 배치를 바꿔야 한다.

**확인된 표시 버그(이 작업에서 고친다)**
- `app/monte-carlo/components/shared.tsx:17`의 `krwTenThousands`는 값을 10,000으로 나누고 "M KRW"를 붙인다.
- 그래서 9,640,000원이 "964 M KRW"로 보인다. 보통 읽는 방식으로는 9억 6,400만 원이 되어, 실제의 100배로 읽힌다.
- 경로·위험 탭의 금액 대부분(중앙 종가, 구간, VaR, CVaR)이 이 함수를 쓴다. 차트 축은 같은 단위의 숫자만 보인다.
- 이 작업에서 고치고 `ERROR-LOG.md`에 기록한다(§3).

**완료 상태**
- 1280×720과 390×844에서, 다섯 탭 모두, 실행 전과 후 모두 페이지 스크롤이 없다.
- 각 탭의 첫 화면이 그 탭의 핵심 수치와 주 차트를 보인다.
- 금액 단위가 올바르게 읽힌다.
- 화면 문구가 ko/en 카탈로그에서 나온다(DS Task 12 M6 Monte Carlo 부분).
- `"/monte-carlo"`가 `ONE_SCREEN_ROUTES`에 들어간다.

**범위 밖**
- 시뮬레이션 엔진, 워커, 결과 정규화, 입력 기본값
- CSV 내용과 파일명(버튼 배치만 바꾼다)
- 새 지표나 새 차트
- 차트 색 규칙. 색은 DS Task 12에서 정했다.

## 1. 배치(1280×720)

**높이 예산**

| 항목 | 높이 |
|---|---|
| 뷰포트 | 720 |
| TopNav와 간격(`--main-pad-top`) | 64 |
| 아래 여백(한 화면 경로의 lg 24px) | 24 |
| **페이지 열** | **632** |
| 헤더(제목 + 부제 한 줄; 시장 개요 헤더와 같은 구성, 같은 예산) | 76 |
| 탭 바(공용 `Tabs`, 시장 개요와 같은 모양) | 53 |
| **탭 패널** | **503** |

주 차트 영역은 503 − 수치 줄 72 − 간격 12 ≈ **419**다.

**페이지 프레임**
- 헤더 구성은 시장 개요 헤더를 기준으로 삼는다(내 판단, 빌더 검토 뒤). 지금의 `PageHeader`는 eyebrow와 `mb-6` 때문에 100px가 넘는다.
- eyebrow는 빼고 제목과 부제 한 줄만 남긴다.
- 부제를 짧게 바꾼다. 390px에서도 한 줄이어야 한다.
  - en: "Path, risk, distribution, valuation and correlation simulations"
  - ko: "경로·위험·분포·가치평가·상관 시뮬레이션"
  - 390px에서 넘치면 말줄임(truncate)한다.
- 탭 카드 다섯 개의 설명문은 지운다.
- 탭은 공용 `Tabs`로 바꾼다(화살표 키 탐색). 상태는 `useTabState(tabStateKey("monteCarlo", "tab"), "path")`에 둔다.
- 저장된 값이 다섯 키가 아니면 `"path"`로 돌아간다. `useTabState`는 값을 검사하지 않으므로(`lib/tabState.ts:69`) 페이지가 가드를 둔다(시장 개요의 `isMarketPageTab`과 같은 방식).
- 복원은 effect에서 일어나므로 첫 렌더는 늘 `"path"`다. 이것은 다른 탭 페이지와 같은 동작이고, 그대로 둔다.
- 래퍼의 `px-4 py-6 max-w-7xl`을 없애고 `/corporate`와 같은 열 높이 클래스를 쓴다. 탭 패널은 `min-h-0 flex-1`이다.

**탭 패널 공통 구조**

```
┌ 입력 레일 320 ─────────┐┌ 결과 ───────────────────────────────────────┐
│ 입력칸들                │ 상태 · 핵심 수치 줄 (72)              [내보내기 ▾] │
│ (레일 안에서 스크롤)    │ 주 차트 영역 (나머지, 약 419)                       │
│ ─────────────           │                                                     │
│ [실행]  [취소]  ← 고정   │                                                     │
└────────────────────────┘└─────────────────────────────────────────────┘
```

- 레일 폭은 320px다. 상관 탭의 4×4 상관행렬 입력이 들어가야 하기 때문이다. 지금 캡처에서는 칸이 좁아 값이 잘린다.
- 실행·취소 버튼은 레일 아래에 고정되고, 입력칸만 레일 안에서 스크롤한다.
- 결과 영역 맨 위 줄에 차례로 둔다:
  - 실행 상태(대기 / 실행 중 + 진행률 / 실패 / 취소 / 결과 있음)
  - 핵심 수치(mono)
  - 오른쪽에 "내보내기" 메뉴 하나. 지금의 CSV 버튼들을 메뉴 항목으로 옮긴다.
- 실행 전에는 주 차트 영역에 빈 상태 문구가 들어간다. 영역 높이는 그대로다.
- 정규화 경고(`WarningNotice`)는 수치 줄 아래 한 줄 배너로 둔다. 길면 접힌 상태로 시작한다.
- **390×844(내 판단):**
  - 레일은 결과 위에 "입력" 펼침 단추 하나로 접혀 있다(기본은 접힘).
  - 실행·취소 버튼은 펼침 단추 줄에 늘 보인다.
  - 수치 줄은 2열 격자가 되고, 패널 안에서 스크롤한다.
  - 페이지는 스크롤하지 않는다.
  - "첫 화면에 핵심 수치와 주 차트" 기준은 1280×720에만 적용한다. 390에서는 "페이지 스크롤 없음"과 "실행 버튼이 보임"만 확인한다.
- **실행 상태(내 판단):** 경로 실행의 진행률, 실패, 취소 상태는 위험·분포 탭의 머리 줄에도 보인다. 경로 탭에서 시작한 실행을 위험 탭에서 볼 수 있기 때문이다.
- **상관 탭은 실행만 있다.** 지금 코드에 상관 취소 처리기가 없고(`page.tsx`에는 `cancelPathSimulation`과 `cancelValuationSimulation`만 있다), 엔진은 범위 밖이다. 그래서 `actions`에 실행 버튼만 들어가고, 상태에 "취소"가 나오지 않는다.

## 2. 탭별 내용

| 탭 | 레일 | 수치 줄 | 주 차트 영역 |
|---|---|---|---|
| 경로 | 입력 8칸 + 실행/취소 | 중앙 종가, 기대수익률, 손실확률, 샤프 | 표본 경로 차트 \| 백분위 콘, 나란히 |
| 위험 | 없음. "경로 탭 입력 기준" 한 줄과 경로 탭으로 가는 링크 | VaR 95, VaR 99, CVaR 95, 최대낙폭, 소르티노, 왜도 | 왼쪽 2/3는 차트 보기 전환(VaR/CVaR 분포 \| 종가 백분위), 오른쪽 1/3은 통계 요약 표(패널 안 스크롤) |
| 분포 | 없음(위와 같은 한 줄) | 평균, 표준편차, 첨도, 최대, 최소 | 히스토그램+정규곡선 \| CDF 비교, 나란히 |
| 기업가치 | 티커(가격 자동 조회 포함)와 입력칸 + 실행/취소 | 중앙 공정가치, 저평가 확률, 상승여력, 80% 구간 | 왼쪽 2/3는 공정가치 분포 차트, 오른쪽 1/3은 가치평가 통계 표 |
| 상관 | 자산 4개 표, 상관행렬, 시뮬레이션 수, 실행 | 최적 μ, 포트폴리오 σ, 분산효과, 최적 샤프 | 효율적 프런티어(왼쪽 큰 칸) + 보기 전환(스피어만 민감도 \| 상관 히트맵) |

**탭별 세부 사항**
- 레일에는 지금 화면에 보이는 입력만 둔다. 경로 탭은 `PathSimulationSection.tsx`의 8칸이다. `riskFreeRate`와 `seed`는 지금도 화면에 없으므로 계속 숨긴다.
- 기업가치 레일에서 가격 조회 메시지는 티커 칸 바로 아래에 둔다. 실행 오류와 정규화 경고는 결과 머리 줄 아래 배너로 둔다(모든 탭에서 같다).
- 기업가치의 80% 구간은 접두를 한 번만 쓴다. en은 `KRW 41,200–58,900`, ko는 `41,200–58,900원`이다(en dash).
- 위험·분포 탭에서 경로 실행 결과가 없으면 수치 줄 대신 다음을 보인다: "경로 탭에서 먼저 실행하세요" 문구와 이동 버튼.
- 백분위 구간(5–95, 10–90, 25–75, 중앙)은 지금 별도 카드 4개다. 이를 콘 차트의 범례로 합치고, 범례 항목마다 금액 범위를 함께 적는다.

**지우는 것(정보가 다른 곳에 남는다)**
- 실행 모드 안내 상자. 실행 모드 입력의 도움말 한 줄로 옮긴다.
- 탭마다 있는 요약 카드(제목, 설명문, 항목 4개). 수치 줄과 상태가 대신한다.
- "Simulation Setup" 입력 되풀이 상자. 입력은 레일에 늘 보인다.
- 지표 카드의 설명문(detail). 각 수치의 `title` 툴팁으로 옮긴다. 툴팁 문구도 카탈로그에서 가져온다.

**차트 높이:** 지금 320px 고정이다. 이를 주 차트 영역을 채우는 높이로 바꾼다(flex). 최소 높이는 200px다.

## 3. 금액 단위

| 상황 | 지금 | 바뀐 뒤 |
|---|---|---|
| en | `964 M KRW` (값 9,640,000) | `KRW 9.64M` |
| ko | 같음 | `964만원` |

- 새 포매터는 `formatKrwCompact(value: number, locale): string`다(`lib/format.ts`의 공유 포매터 또는 Monte Carlo 전용 중 어디에 둘지는 계획에서 정한다).
  - en: 백만 원 단위, 소수 2자리, 접두 `KRW `. 1,000,000 미만이면 정수 원으로 쓴다.
  - ko: 만원 단위 정수에 `만원`을 붙인다. 1억 이상이면 `1억 2,345만원` 형식으로 쓴다.
  - 값이 없거나 유한하지 않으면 `—`다.
- **경계 규칙(내 판단, 빌더 검토 뒤):**
  - 반올림: 만원과 백만 원 단위 모두 0에서 먼 쪽으로 반올림한다(Intl 기본).
  - ko에서 10,000원 미만은 원 단위 정수로 쓴다. 예: `9,500원`.
  - ko에서 억의 정확한 배수는 `1억원`이다. `1억 0만원`으로 쓰지 않는다.
  - 음수는 부호를 맨 앞에 둔다. ko는 `-964만원`, en은 `-KRW 9.64M`이다.
  - en에서 1,000,000원 미만은 `KRW 950,000`으로 쓴다.
- **포매터 단위 테스트 값:**
  - en: `9_640_000` → `KRW 9.64M`, `950_000` → `KRW 950,000`, `-9_640_000` → `-KRW 9.64M`
  - ko: `9_640_000` → `964만원`, `123_450_000` → `1억 2,345만원`, `100_000_000` → `1억원`, `9_500` → `9,500원`, `-9_640_000` → `-964만원`
  - 공통: `NaN` → `—`
- 차트 Y축 눈금도 같은 단위로 맞춘다. en은 백만 단위 숫자, ko는 만원 단위 숫자이고, 축 제목에 단위를 적는다. 대상은 다음과 같다.
  - 경로 탭 차트 두 개
  - 위험 탭 종가 백분위 차트. 지금 `RiskAnalysisSection.tsx:109-114`는 `TEN_THOUSAND_KRW`로 나누고, `:129`는 `valueLabel="M KRW"`로 단위를 박아 둔다.
- `krw()`(기업가치 탭의 주당 가격, `KRW 50,000`)는 그대로 둔다. 원 단위가 맞기 때문이다.
- `ERROR-LOG.md`에 기록할 내용: 증상("964 M KRW"), 원인(만원 나눗셈에 M 라벨), 고친 커밋, 재발 방지(단위 테스트로 en/ko 문자열 고정).

## 4. i18n

- Monte Carlo 화면의 모든 보이는 영어 문구를 `monteCarlo.*` 카탈로그로 옮긴다(en/ko). 대상은 다음과 같다:
  - 입력 라벨, 버튼, 상태
  - 수치 라벨과 툴팁
  - 차트 제목, 설명, 범례
  - 빈 상태와 오류
  - 가격 조회 메시지
  - 표 머리말
- `page.tsx`의 가격 조회 메시지(지금 영어 템플릿 문자열)도 키와 변수로 바꾼다.
- 지운 문구의 기존 카탈로그 키는 함께 지운다.

| 금액 포매터(순수 함수, 모델 스펙): en `9_640_000` → `KRW 9.64M`; ko → `964만원`; ko `123_450_000` → `1억 2,345만원`; `NaN` → `—` | `M KRW` 라벨로 되돌린다. 억 단위 처리를 뺀다. |
| ko 전환에서 입력 라벨, 버튼, 차트 제목이 한국어다. | 영어를 직접 쓴다. |

### 5.2 기존 테스트
