# 종목 상세 원스크린 (급락 경보 ④-b)

작성일: 2026-10-25. 브랜치 `feat/stock-detail-screen`(renewal 0fc0cbb에서 분기).
상위 스펙: `2026-10-18-risk-signal-design.md` §4. 앞 단계: ④-a `2026-10-25-news-history-design.md`(#78 병합)
브레인스토밍 와이어프레임 v1~v3: `.superpowers/brainstorm/`(git 제외, 이 PC에만 있다).

## 1. 의도

오너는 관심종목이나 경보 카드에서 종목을 열었을 때 **그 종목의 지금 흐름을 한 화면에서 전체적으로 보기**를 원한다.
오너의 말: "1주 추세, 1달 추세, 6개월 추세, 어제 장 상황, 뉴스 등을 전체적으로 볼 수 있으면 좋겠어."

특히 차트에서는 "큰 움직임이 언제 왜 있었는지" 보려 한다. 이 화면이 답해야 할 질문은 세 가지다.

- 그날 시장 전체가 움직였나?
- 같은 테마가 같이 움직였나?
- 이 종목만 움직였나?

지금의 `/detail/[ticker]`는 이렇게 생겼다(2026-10-25 캡처, 높이 1844px로 한 화면 720px의 약 2.5배).

- 위에서 아래로 가격 → 5년 차트 + 기술지표 → DCF 워크벤치 → 기업 진단이 쌓여 있다.
- 회사 이름, 섹터, 테마, 뉴스, 위험 신호 상태가 없다.
- DCF와 진단은 기업 분석(`/corporate`)과 겹치고, 버튼을 눌러야 채워진다.

## 2. 목표, 하지 않을 것, 실패로 보는 것

**목표**

- 1280×720 한 화면, 페이지 스크롤 없음. `ONE_SCREEN_ROUTES`에 `/detail`을 넣는다.
- 1주·1달·6개월 추세와 어제 장 상황을 위쪽 타일로 한눈에 보인다.
- "왜 움직였나" 차트를 만든다.
  - 큰 움직임이 있던 날을 표시하고, 누르면 시장, 테마, 같은 테마 종목, 이벤트, 뉴스로 이유를 보인다.
  - 기준값은 오너가 바꿀 수 있고, 바꾸면 표시가 바로 다시 그려진다.
- 뉴스 칸을 둔다. 누른 날의 뉴스, 아니면 최신 뉴스이고, 게시 시각을 아는 경우에만 시각을 보인다.
- 관심종목 전체의 전일 급등·급락 목록을 두고, 누르면 그 종목으로 이동한다.

**하지 않을 것**

- DCF 워크벤치와 기업 진단을 이 화면에 두는 것. "기업 분석에서 보기" 링크로 대체한다.
- 장중(분 단위) 차트. 오너: "분 단위 흐름 차트는 필요없어."
- 새 데이터 출처. 일봉, 테마 지수, 이벤트, 경보, 뉴스 모두 이미 있는 것을 쓴다.

**실패로 보는 것**

- 페이지가 720px을 넘어 스크롤된다.
- 큰 움직임 설명이 사실과 다르다. 예를 들어 다른 날의 수치나, 계산할 수 없는데 0으로 보이는 값.
- 뉴스가 없는 날을 "뉴스 없음"으로 단정한다. 실제로는 검색하지 않았을 뿐이므로, 그때는 [이 날짜 뉴스 찾기]를 보인다.
- 가짜 게시 시각을 보인다.

## 4. 현재 상태와 근거

### 4.2 큰 움직임 기준 실측(최근 1년, 252거래일)

| 종목 | 가격 2배 이상 | + 거래량 2배 | + 거래량 1.5배 | 고정 ±5% |
| --- | --- | --- | --- | --- |
| AAPL | 15 | 2 | 6 | 2 |
| NVDA | 10 | 2 | 3 | 8 |
| MSFT | 15 | 6 | 9 | 4 |
| AMD | 10 | 5 | 6 | 52 |
| XOM | 19 | 0 | 4 | 1 |
| MU | 18 | 1 | 9 | 71 |

- 가격 상대 기준은 종목과 관계없이 한 달에 한두 번 걸린다.
- 거래량 2배를 "그리고" 조건으로 쓰면 너무 엄격하다(XOM은 1년에 0일). 그래서 거래량은 거르는 조건이 아니라 더 강한 표시(●)로 쓴다(S-D6).
- 고정 퍼센트는 종목마다 크게 달라서 쓰지 않는다.

## 5. 설계

### 5.1 배치(1280×720, v3 와이어프레임)

1. **맨 위 한 줄**
   - 티커, 회사 이름, 섹터, 테마 이름(한·영), 최근 종가와 등락, 기준일.
   - 이 종목이 지금 경보의 급락 카드나 위험 후보 카드에 있으면 배지를 단다.
   - "기업 분석에서 보기" 링크: 누르면 `/corporate`가 그 종목으로 열린다. 기업 분석 화면이 주소의 종목을 읽게 한다. 지금은 세션 저장값만 읽는다.
2. **타일 4개**
   - 1주(5거래일), 1달(21거래일), 6개월(126거래일) 추세 타일: 등락률과 작은 추이선을 보인다.
     - 1주 타일에는 종가가 20일 이동평균 위인지 아래인지를 넣는다.
     - 1달 타일에는 50일 이동평균 위인지 아래인지를 넣는다.
     - 6개월 타일에는 6개월 고점 대비 위치를 넣는다.
   - 어제 장 타일: 최신 거래일의 등락률, 고가와 저가, 거래량 배수(직전 20거래일 평균 대비), RSI(14)를 보인다.
3. **차트(왼쪽 가운데)**
   - 기본 6개월이고 1년, 5년을 고를 수 있다. 캔들, 거래량, 이벤트선(켜기/끄기 하나)을 그린다.
   - 큰 움직임 표시는 ○와 ●다(§5.2). 기준 입력 칸 두 개(가격 ×, 거래량 ×)는 차트 머리에 둔다.
   - 표시를 누르면 설명 카드가 뜬다(§5.3). 다시 누르거나 Esc를 누르면 닫힌다.
4. **뉴스 칸(가운데 오른쪽)**
   - 누른 날이 있으면 그날 기준 앞뒤 2일(④-a 검색 기간과 같음)의 이 종목 뉴스와 테마 뉴스를 보인다. 없으면 최신 뉴스다.
   - 줄마다 제목, 매체, 시각을 보인다. `published_at`이 null이면 시각 대신 날짜만 보인다.
5. **전일 급등·급락 목록(오른쪽)**
   - 관심종목 전체에서 최신 거래일 등락률 상위 5개와 하위 5개를 보인다. 줄마다 티커, 등락률, 테마가 있다.
   - 누르면 그 종목 상세로 이동하고, 지금 종목은 강조한다.

모든 문구는 한·영 카탈로그에 넣는다. 색, 글꼴, 크기는 디자인 토큰만 쓴다(CLAUDE.md §10, `DESIGN.md`).

### 5.2 큰 움직임 판정(S-D6, S-D7)

거래일 t마다 다음을 계산한다.

- `r_t = close_t / close_{t-1} - 1`
- `sd_t` = 직전 60거래일(t-60..t-1)의 일간 수익률 표준편차. 60개가 안 되면 판정하지 않는다.
- `price_ratio_t = |r_t| / sd_t`
- `vol_ratio_t = volume_t / mean(volume_{t-20..t-1})`. 20개가 안 되거나 평균이 0이면 거래량 판정은 하지 않는다.

판정:

- `price_ratio_t >= 가격 기준`이면 ○(오른 날과 내린 날을 색으로 구분)이다.
- 거기에 더해 거래량 기준이 0보다 크고 `vol_ratio_t >= 거래량 기준`이면 ●다.
- 기준 입력: 가격 기준은 0.5~10, 거래량 기준은 0~10, 0.1 단위다. 기본값은 각각 2.0과 2.0이다.
- 판정은 화면에서 일봉으로 계산한다. 입력을 바꾸면 서버에 묻지 않고 바로 다시 그린다.
- 표시는 고른 기간 안의 날에만 그린다. 다만 `sd`와 평균 거래량은 기간 밖 과거 일봉까지 써서 계산한다.

### 5.3 설명 카드("왜 움직였나")

새 API 하나: `GET /api/v1/detail/{ticker}/move/{date}`. 응답 계약:

```
{
  "ticker": "AAPL", "date": "2026-10-08",
  "return_pct": -6.2,                         // 그날 종목 등락률(%)
  "price_ratio": 3.1, "volume_ratio": 2.4,    // §5.2 값, 계산 불가면 null
  "market": {"ticker": "^GSPC", "return_pct": -1.1},          // 없으면 null
  "theme": {"id": "ai", "label": {"en": "...", "ko": "..."},
            "return_pct": -4.8},                               // 테마 없음/계산 불가면 null
  "peers": [{"ticker": "NVDA", "name": "...", "return_pct": -7.0}, ...],
                                              // 같은 테마의 다른 관심종목, 등락률 오름차순, 그날 일봉이 없는 종목은 제외
  "events": [{"category": "...", "title": "..."}],            // 그날 시장 이벤트
  "alerts": [{"id": 11, "kind": "risk", "role": "start"}],    // S-D14: kind risk|surge, role start|ongoing|end
  "news": {"stored": 3, "searched": true}     // 그날 앞뒤 2일의 저장된 이 종목 뉴스 수, 그 기간을 검색한 적이 있는지
}
```

- 관심종목이 아닌 종목(S-D12)은 404를 내지 않는다. `theme`은 null, `peers`는 빈 목록, `news`는 null로 응답한다. 시장 지수 자신이면 `market`도 null이다. 422: 그날 그 종목 일봉이 없음. 404: 일봉 자체가 없는 종목.
- 테마 등락률은 기존 테마 지수(시가총액 가중)의 그날 변화다. 같은 테마 종목 목록은 관심종목의 `theme`을 따른다.

화면 표시:

- 종목, S&P 500, 테마 평균을 나란히 보인다. 그 아래에 같은 테마 종목의 등락률을 칩 목록으로 보인다(많으면 위아래 몇 개와 "+N").
- 이벤트와 경보를 보인다.
- 뉴스는 저장된 수를 보이고, 뉴스 칸이 그날로 바뀐다.
- `news.stored == 0`이고 `searched == false`이면 [이 날짜 뉴스 찾기]를 보인다.
  - 누르면 `POST /api/v1/news/history`를 부르고, 기다리는 동안 상태를 표시한다(보통 3~8초).
  - 결과 상태가 `blocked`나 `daily_limit`이면 `retry_after`와 함께 "지금은 검색할 수 없음"을 보인다.
- `stored == 0`이고 `searched == true`이면 "이 기간 검색 결과 없음"이다.

### 5.4 전일 급등·급락 API

새 API 하나: `GET /api/v1/detail/movers/latest`. 응답 계약:

```
{ "date": "2026-10-23",
  "up":   [{"ticker": "NVDA", "name": "...", "theme": "ai", "return_pct": 6.2}, ...],   // 최대 5, 내림차순
  "down": [{"ticker": "INTC", "name": "...", "theme": "...", "return_pct": -7.4}, ...]  // 최대 5, 오름차순
}
```

- 대상은 관심종목 전체 중 최신 거래일과 그 전 거래일 일봉이 모두 있는 종목이다.
- 날짜는 관심종목 일봉의 가장 최근 공통 거래일이다. 일부 종목만 다음 날 봉이 들어온 경우, 그 종목 몇 개로 날짜를 정하지 않는다.
- 계산은 저장 없이 한다(S-D11).

### 5.5 경보 배지

맨 위 배지는 진행 중 경보가 있을 때(`GET /api/v1/risk/latest`) 그 경보의 전체 카드(`GET /api/v1/risk/alerts/{id}?cards=all`)에 이 종목이 있을 때만 보인다(S-D15). 급락 카드인지 위험 후보 카드인지 구분한다.

## 6. 테스트

모든 새 테스트는 변이 검사를 한다(CLAUDE.md §8).

- **백엔드(pytest)**
  - `/move/{date}`:
    - 종목, 시장, 테마, 같은 테마 종목의 등락률이 고정 입력 일봉과 정확히 맞는다.
    - 그날 봉이 없는 종목은 같은 테마 목록에서 빠진다.
    - 테마가 없으면 `theme`이 null이다.
    - 404와 422.
    - `news.searched`가 검색 기록을 따른다.
  - `/movers/latest`:
    - 상하위 5개와 정렬.
    - 최신 공통 거래일 규칙(한 종목만 봉이 앞서 있는 경우).
- **프런트엔드(Playwright, API 목)**
  - 1280×720에서 `/detail/AAPL`이 스크롤되지 않는다(one-screen 검사에 `/detail` 추가).
  - 타일 수치가 목 일봉에서 계산한 값과 맞는다.
  - 큰 움직임:
    - 기본 2배에서 고정 일봉의 정해진 날에만 ○/●가 그려진다.
    - 가격 기준을 바꾸면 표시 수가 바뀐다.
    - 거래량 기준 0이면 ●가 없다.
    - 설정이 새로고침 뒤에도 남는다.
    - 저장소가 막혀도 기본값으로 동작한다.
  - 설명 카드:
    - 표시를 누르면 카드가 뜨고, 뉴스 칸이 그날로 바뀐다.
    - [이 날짜 뉴스 찾기] → 검색 중 → 결과, 그리고 `blocked` 상태 문구.
  - 뉴스 줄은 `published_at` null이면 시각을 그리지 않는다.
  - 급등·급락 목록을 누르면 그 종목으로 이동한다.
  - "기업 분석에서 보기"를 누르면 기업 분석이 그 종목으로 열린다.
  - 한국어 화면에서 위 문구가 한국어로 나온다.

- 컴포넌트 나누기와 파일 위치(기존 `components/charts`, `components/risk` 패턴을 따른다).
