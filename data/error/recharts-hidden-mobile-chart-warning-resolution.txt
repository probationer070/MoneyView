Issue

Playwright runs were still logging Recharts browser warnings about `width(0)` and `height(0)` during hidden or mobile chart rendering. The suite was not failing on those warnings, but the warnings indicated that some charts were mounting before their parent container had a measurable size.

Root Cause

The problem was not bad chart data and it was not a missing `minWidth` or `initialDimension` setting by itself.

Several Recharts components were still using `ResponsiveContainer` directly inside UI regions that can temporarily render at zero size:

- mobile-hidden table cells
- breakpoint-driven layouts
- temporarily collapsed or hidden panels

When those parents reported `0 x 0`, Recharts emitted browser warnings during mount.

Resolution

A shared wrapper was added at:

- `apps/web/components/ui/ResponsiveChart.tsx`

What it does:

- measures the parent node with `ResizeObserver`
- stores the current width and height
- mounts `ResponsiveContainer` only after the parent size is at least `minWidth` and `minHeight`

This changes the render timing so Recharts does not initialize against a zero-sized container.
